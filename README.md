# Video Tips

動画編集の「気持ちよさ」を、再現可能な編集ルールとして蓄積する。

## ジェットカット

### 基本
- 間を切り詰める
- 息継ぎ、沈黙、言い直しなど不要な時間を削る
- 内容のリズムを保ちながら、視聴テンポを上げる

### テロップ
- 1画面の文字量は14文字以下を基本とする
- 一瞬で読めることを優先する
- 文章を詰め込まず、映像と音声に役割を分ける

### 上部バナー
- 画面上部に固定バナーを置く
- シリーズや動画全体の文脈を常に示す
- バナーの色、フォント、余白、形を統一する

### トンマナ
動画全体で「色・文字・形・余白・動き」のルールを揃える。

色やフォントが映像と合っていると、視聴者は意識せず気持ちよく見られる。
逆に、要素ごとのデザインがちぐはぐだと、情報が読めても違和感が生まれる。

## 編集原則

**時間を削る。**
**文字を削る。**
**視覚ルールを揃える。**

ジェットカットは単に速くする編集ではなく、
「時間・言葉・デザイン」を同じリズムに揃える編集として考える。
